# Lời giải đề thi Python – Mã đề 11301

Đây là lời giải tham khảo cho đề thi kết thúc môn **Lập trình Python**, mã đề 11301 (5 câu, tổng 10 điểm).

## Nội dung

| File | Nội dung |
|---|---|
| `cau1_so_nguyen.py` | Kiểm tra n, đếm chữ số lẻ, tính tổng phân số |
| `cau2_chuoi.py` | Đếm chữ hoa, kiểm tra đối xứng, tính tổng chữ số |
| `cau3_danh_sach.py` | Nhập danh sách, tính tổng số dương chẵn, đếm phần tử |
| `cau4_quan_ly_sach.py` | Lưu và xóa thông tin sách bằng dictionary |
| `cau5_dien_thoai.py` | Tạo lớp DienThoai và hai đối tượng mẫu |

## Cách chạy

Mở Terminal tại thư mục gốc repository rồi chạy từng câu:

```bash
python exams/python-229152-11301/cau1_so_nguyen.py
python exams/python-229152-11301/cau2_chuoi.py
python exams/python-229152-11301/cau3_danh_sach.py
python exams/python-229152-11301/cau4_quan_ly_sach.py
python exams/python-229152-11301/cau5_dien_thoai.py
```

Nếu máy dùng lệnh `py`, thay `python` bằng `py`.

## Ghi chú

- Các chương trình được tách riêng để dễ học và chạy từng câu.
- Câu 1 kiểm tra n trong đoạn từ 1 đến 1500 như đề yêu cầu.
- Câu 4 kiểm tra năm xuất bản không lớn hơn năm hiện tại.
- Câu 5 dùng đúng tên thuộc tính và phương thức theo đề: `MaMay`, `TenMay`, `HangSanXuat`, `DungLuongPin`, `GiaBan`, `thongtindienthoai()`.
- Đây là lời giải tham khảo được viết rõ ràng hơn để dễ hiểu; nên tự chạy và luyện gõ lại từng câu.
